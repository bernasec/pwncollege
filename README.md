# pwn.college study repository
This repository contains the code, scripts, and solutions I've developed while working through challenges on [pwn.college](https://pwn.college), a platform focused on cybersecurity and binary exploitation education.
 
## Purpose
This repo exists purely to document my personal learning journey. It's a record of the exercises I've completed and the approaches I used to solve them.
 
>If you're a fellow student stuck on a challenge and stumbled upon this repo, feel free to take a look around. That said, I'd strongly encourage you to try everything on your own first. struggle through it, experiment, and give it a real shot before checking the solutions. That's where most of the actual learning happens.
 
### Status
This repository is a work in progress. It will keep growing as I move through more modules and challenges on the platform, so expect new content to show up regularly.
